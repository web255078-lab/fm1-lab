4. 送信テスト（ブラウザ → 実機の鍵盤が光るか）

Felucca の README には「鍵盤は、シーケンサーと MIDI IN が鳴らしている音を表示する」とあります。LED だけを光らせる専用命令は書かれていないので、ここではノートオン（音を鳴らす命令）を送って、鍵盤が光るか・音が鳴るかを見ます。

純正ファームで光るか、強さ1でも音が鳴るか、送った音が実機の MIDI OUT から跳ね返ってくるか（エコー）は未確認です。
