自分の音を作って保存

この章は、取扱説明書や各ファームの説明をもとに書いた下書きです。実機で確かめられていない操作は【要実機確認】としています。FM-1 が届いたら、接続診断の「実機確認メモ」をもとに直します。

FM-1 の EDIT は奥が深いので、最初から全部いじる必要はありません。この章では、気に入ったプリセットを土台に、エンベロープ・LFO・エフェクトの3つで自分の音にして、保存するところまでやります。

保存は「いま選んでいる番号」に上書きされます（説明書の書き方から）。そして PRESETS を回すと、すぐ別の音が読み込まれます。なので、先に保存先にしたい番号のプリセットを選んでから音を作り始めてください。消えてもいい番号（たとえば 120〜128）を自分用にするのがおすすめです。
9-1

音の時間の形を変える

やってみる

自分用の番号のプリセットを選び、ENV を押します。KNOB 1〜4 が Attack・Decay・Sustain・Release（それぞれ 0〜8）です。第5章と同じように、ふわっと始まる音、すぐ消える音を作ってみてください。

何が起きたか

第5章のブラウザのシンセとまったく同じ考え方で、FM-1 の音の時間の形が変わりました。画面では、値がブロックの棒グラフで表示されます。

それの名前

音量の時間の形がエンベロープ、4つのつまみはその頭文字で ADSR。FM-1 では EDIT の中にも、オペレーターごとの細かい形（Rate 1〜4・Level 1〜4）があります。

ENV の画面のつまみが、6つのオペレーターのどれに効くのか（全部まとめてか）は、説明書に書かれていません。
9-2

揺らす

やってみる

LFO を押します。1ページ目の KNOB 1 が揺れの形、KNOB 2 が揺れの速さ、KNOB 3 と KNOB 4 は「何を揺らすか」の量です。鍵盤を押しっぱなしにして、KNOB 3 と KNOB 4 を1つずつ上げて、ちがいを聞いてください。

揺れの効き具合は、2ページ目の KNOB 2（高さへの効き具合）や、EDIT の各オペレーターの設定でも変わるようです。KNOB 3 を上げても高さが揺れないときは、2ページ目の KNOB 2 を上げてみてください。
何が起きたか

KNOB 3 では音の高さが、KNOB 4 では音の大きさがゆれました。第5章の「揺らす先」が、FM-1 では2つのつまみに分かれています。

それの名前

PMD はピッチ・モジュレーション・デプス（高さの揺れの深さ）、AMD はアンプリチュード・モジュレーション・デプス（大きさの揺れの深さ）です。

9-3

エフェクトを並べる

やってみる

FX を押すと、6つのエフェクトが 3×2 のマス目で出ます。SELECT で選び、KNOB 1〜3 で調整、KNOB 4 を右に回すと ON、左で OFF です。SEL を押してから SELECT を回すと、順番を入れ替えられます。

何が起きたか

Filter（フィルター）・Reverb（響き）・Delay（こだま）・Distortion（歪み）・Chorus（ゆらぎ）・Phaser（うねり）の6つが、マス目の順に音にかかります。明るいマスが ON、暗いマスが OFF です。

それの名前

エフェクトを順番につないだものをエフェクトチェーンといいます。順番で音が変わります。たとえば「歪み → 響き」と「響き → 歪み」では、響きまで歪むかどうかが違います。

9-4

保存する

やってみる

できた音は、SAVE を長押しすると保存されます。SAVE の LED が光り、画面に Preset Saved と出ます。保存したら、PRESETS で別の音にしてから戻ってきて、ちゃんと残っているか確かめてください。

GLO の2ページ目にある Reset Patches は、128個全部を工場出荷の状態に戻します（説明書より）。自分の音も消えるので、押すときは注意。
何が起きたか

別の音から戻ってきても、作った音が残っていました。説明書によると、SAVE ではエフェクトやシーケンサーのパターン、全体の設定なども一緒に保存されます。

それの名前

本体の電源を切っても消えない記憶をフラッシュメモリーといいます。
