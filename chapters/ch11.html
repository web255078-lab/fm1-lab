ファーム入れ替えの基本と安全

この章は、取扱説明書や各ファームの説明をもとに書いた下書きです。実機で確かめられていない操作は【要実機確認】としています。FM-1 が届いたら、接続診断の「実機確認メモ」をもとに直します。

FM-1 の中のプログラム（ファームウェア）を入れ替えると、まったく別の楽器になります。とても楽しい一方で、失敗すると起動しなくなることもあります。この章は、遊ぶ前の安全講習です。

ここで扱うファームは、純正以外はすべて有志が作ったもので、どれも「自己責任で」と書かれています。この教材も、うまくいくことを保証できません。
11-1

入れ替えの流れ

やってみる

どのファームも、だいたい同じ流れです。

  1. PC の Chrome か Edge で、そのファームのインストールページを開く（Android の Chrome で入れられると書かれたファームもありますが、困ったときの立て直しは PC の方が確実です）
  2. FM-1 を データ通信できる USB ケーブルで PC に直接つなぐ（ハブは使わない）
  3. MIDI を使うほかのアプリやタブを閉じる（この教材のタブも）
  4. インストールのボタンを押し、終わるまでケーブルを抜かない・PC をスリープさせない

まだ入れなくてOK。ファーム図鑑で、気になるものを1つ選んで、その「純正に戻す方法」を読んでおいてください。

何が起きたか

多くのファームは、ブラウザだけで入れられて、PC に何もインストールしなくて済みます。ただし手順の途中で止まると危ないので、ケーブル・アプリ・電源の3つに気をつけます。

それの名前

本体の中のプログラムをファームウェア、入れ替えることを書き込み（フラッシュ）、有志が作ったものをカスタムファームウェア（CFW）と呼びます。

11-2

純正に戻す方法を知っておく

やってみる

戻し方は大きく2つです。

  • インストーラーの「Return to official V15」など：多くの有志ファームのインストールページにある。M-VAVE の公式ファイル（V15）を使う
  • M-VAVE 公式の M-UPGRADE：Windows・Mac 用の更新ソフト。m-vave.com/download から

M-VAVE のダウンロードページで、FM-1 のファイル（V15）があることを確かめてください。

M-VAVE のページには、Windows／Mac 用の FM-1 ファームが V14、PC Firmware として V15（.fwsc）が載っていました（2026年10月時点）。どれを使うかは実機と各インストーラーの案内で確かめてください。
何が起きたか

どのファームに行っても、「純正に戻る道」が用意されています。M-UPGRADE で「Failed to enter upgrade mode!」と出たときは、ソフトを開いたまま USB を挿し直して続けるよう、公式ページに書かれています。

それの名前

工場出荷のファームを純正ファーム（ストックファーム）と呼びます。この教材の第2部は純正が前提です。

11-3

困ったときの手順

やってみる

書き込みに失敗して画面が真っ暗のままになったときの、有志ファームの説明書に共通する手順です。読むだけでOK。

  1. PC に WL80UBOOT という名前の機器（または USB の ID 4C4A:8057）が見えているか確かめる＝書き込み待ちの状態
  2. 別のデータ用 USB ケーブルに替える
  3. MIDI を使うほかのアプリを閉じる
  4. インストーラーをもう一度動かす
  5. それでもだめなら、各説明書にある復旧の道具（FM-1 Transporter など）へ。ここは上級者向け
何が起きたか

真っ暗でも、多くの場合は「書き込みを待っている状態」で、もう一度書き込めば戻ります。あわてて何度も抜き差しするより、ケーブルとアプリを見直すのが先です。

それの名前

起動できない状態を俗に文鎮化（ブリック）と言います。FM-1 は、くり返し起動に失敗すると書き込みを待つ状態になる、と説明しているファームもあります。

11-4

記録を残してから入れる

やってみる

入れ替えると、いまのファームの中の音やパターンは消えることがあります。

  • 純正：自分で作ったプリセット番号と設定をメモしておく（第9章）
  • Felucca・Melodee など：インストーラーが先にバックアップを取る仕組みがあるものも（各説明書）
  • X0X：専用のバックアップページでファイルに保存できる
何が起きたか

ファームによって、記録の残し方が違いました。共通するのは「入れる前に残す」です。

それの名前

入れ替える前の記録の保存をバックアップ、戻すことをリストアといいます。
