スケールとコード

音を順に並べると、メロディーの材料になります。音を同時に重ねると、響きになります。この章はその2つです。

いくつかの音を同時に押さえる場面があります。マウスや1本指のときは、鍵盤の上の「和音モード」を ON にすると、タップした鍵盤が押さえたままになります（もう一度タップで離す）。PCキーボードなら A・D・G のように同時押しできます。

4-1

出発点で、雰囲気が変わる

やってみる

白い鍵盤だけで、2通り弾いてください。

  1. ドから右へ、次のドまで
  2. ラから右へ、次のラまで

使う鍵盤はほとんど同じなのに、聞こえ方はどうでしょう。

何が起きたか

ドから始めると、明るく、晴れやかに聞こえます。ラから始めると、少しさみしく、落ち着いた感じになります。

違いは半音のある場所です。白い鍵盤どうしが直接となり合う「ミ・ファ」「シ・ド」（第2章）が、出発点から数えて何番目に来るかで、雰囲気が決まります。

それの名前

決まった並び方で音を順に並べたものをスケール（音階）といいます。

  • ドから：メジャースケール（長音階）。並びは 全・全・半・全・全・全・半
  • ラから：マイナースケール（短音階）。並びは 全・半・全・全・半・全・全

出発点の音をキー（主音）と呼びます。「ドから始まるメジャー」がCメジャー、「ラから始まるマイナー」がAマイナーです。

課題 4-1　ソのメジャースケール

ソから、メジャーの並び「全・全・半・全・全・全・半」で次のソまで弾きます。白い鍵盤だけでは、どこかで足りなくなります。

未挑戦

4-2

3つを重ねる

やってみる

ド・ミ・ソを同時に押さえてください（白い鍵盤を1つ飛ばしで3つ）。PCキーボードなら A・D・G。

何が起きたか

3つの音が混ざって、1つのまとまった響きになりました。バラバラに鳴っているのに、きれいに溶け合って聞こえます。

それの名前

同時に鳴らす音のまとまりを和音、またはコードといいます。ドの上に1つ飛ばしで3つ重ねたこの和音はCメジャー（書くときは C）。

いちばん下の、名前のもとになる音をルート（根音）と呼びます。

4-3

明るい和音・暗い和音

やってみる

ド・ミ・ソ を押さえたあと、真ん中のミだけを、すぐ左の黒い鍵盤（ミ♭）に変えて押さえてください。

何が起きたか

真ん中を半音下げただけで、明るかった響きが、急にくもった、さみしい響きに変わりました。4-1 のメジャーとマイナーの違いと、よく似ています。

それの名前

明るい方がメジャーコード、暗い方がマイナーコード。ド・ミ♭・ソ は Cm（Cマイナー）と書きます。

鍵盤で数えると：

  • メジャー：ルートから 半音4つ 上、そこから 半音3つ 上
  • マイナー：ルートから 半音3つ 上、そこから 半音4つ 上

3つの音の上下を入れ替えて押さえても、同じコードとして響きます（転回形）。この教材の課題では、どの順番・どの高さで押さえてもOKです。

課題 4-3A　コードを押さえよう

C・F・G・Am・Dm・Em の6つ。白い鍵盤だけで作れるコードです。名前を見て、ルートから1つ飛ばしで3つ。わからなければ「答えを光らせる」。

未挑戦

課題 4-3B　耳で明暗

コードが1つ鳴ります。明るい（メジャー）か、暗い（マイナー）か。6問中5問正解でクリア。

未挑戦

4-4

コードをつなぐ

やってみる

光る鍵盤にそって、C → Am → F → G の順に押さえていきます。最後まで行ったら、もう一度 C に戻ってみてください。

Am・F・G は、手を大きく動かさずに済むよう、4-3 の「転回形」（音を並べ替えた形）で光ります。たとえば Am はラ・ド・ミですが、ド・ミ・ラの形で光ります。どの形で押さえても正解です。

何が起きたか

1つずつだと「ただの響き」だったコードが、つなげると物語のように聞こえました。G で「まだ続く」感じがして、C に戻ると「帰ってきた」と落ち着きます。

それの名前

コードの並びをコード進行といいます。C → Am → F → G は、昔から数えきれない曲で使われてきた定番の進行です。

落ち着く場所になるコード（ここでは C）をトニックと呼びます。

Melodee と Felucca には「コードキー」（1つの鍵盤でコードを鳴らす機能）があると README に書かれています（Felucca は SCL の CHORD ページ、第12章）。純正の取扱説明書には、コードキーの記載はありません。
章末課題

はじめての伴奏

メトロノームに合わせて、C → G → Am → F を1小節ずつ。各小節の1拍目に、そのコードがそろっているように押さえ替えます。BPM 70 で4小節、平均70点以上でクリア。

次のコードは、前の小節の4拍目あたりで画面に出ます。最初は「光らせる」を ON に。慣れたら OFF で挑戦。

できるようになったこと

    FM-1 が届いたら

    実機の鍵盤なら指で同時に押さえられるので、和音モードは要りません。何音まで同時に鳴るかは、ファームによって違います（Felucca は全トラック合わせて8音を分け合う、と README にあります）。

    FM-1 の取扱説明書（英語版）によると、純正はPOLY モードで最大12音まで同時に鳴らせます（MONO モードでは1音ずつ）。
