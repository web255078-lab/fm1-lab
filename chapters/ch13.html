楽器を乗り換える（X0X で組む・MAKU と AMB-1 に任せる）

この章は、取扱説明書や各ファームの説明をもとに書いた下書きです。実機で確かめられていない操作は【要実機確認】としています。FM-1 が届いたら、接続診断の「実機確認メモ」をもとに直します。

同じ FM-1 が、ファーム1つで「自分で組むリズムマシン」にも「勝手に鳴り続ける環境音楽の機械」にもなります。この章では正反対の2タイプを乗り換えて、組む楽しさと任せて選ぶ楽しさを比べます。

13-1

X0X：909と808と303

やってみる

X0X は、名作リズムマシン909・808、ベースマシン303（2台）、ブレイクビーツを1台にしたファームです。入れたら、まず次のことをやってみてください（公式マニュアルの最初の手順をもとに、この教材向けにまとめています）。

  • 黒鍵で楽器を選び、白鍵でマスを ON にする。キックを4つ打ち（1・5・9・13）に
  • PLAY で再生。クラップを5と13に、開いたハットを3・7・11・15に
  • ALGORITHM で 909 → 808 → 303A → 303B → BREAK とパートを切り替えられる
何が起きたか

キックが1拍ごとに鳴る「4つ打ち」に、クラップと開いたハットが乗って、本物のダンスビートになりました。白鍵の1・5・9・13は、第3章の1拍目〜4拍目の頭です。X0X ではパターンを最大64ステップ（16ずつ OCT で切り替え）まで作れます。

それの名前

この節の出典：X0X 公式マニュアル「Getting started」の手順1〜4

909・808・303 は、どれも1980年代のローランドの機材の型番で、今でもダンス音楽の音の代名詞です。X0X はそれらを手本にした音を、この FM-1 の中で鳴らしています。

13-2

303のラインを生成する

やってみる

ALGORITHM で 303A を選び、ARP を押します。OCT+ を押すたびに新しいベースラインが生まれ、OCT− でいまのラインを少しだけ変えられます。気に入るまで押してみてください。

そのあと EDIT を押して、KNOB 1（フィルターの明るさ）と KNOB 2（クセ）を回すと、あの「ビヨビヨ」した音になります。

何が起きたか

押すたびに違うフレーズが出てくるので、作曲の知識がなくても、かっこいいベースラインに出会えました。生成ページの DENS（音の数）・ACCENT・SLIDE で、次に生まれるラインの傾向を変えられます。

それの名前

この節の出典：X0X 公式マニュアル「Getting started」の手順5〜6と「TB-3PO」の節

303 の独特の音は、フィルターのクセ（第5章のレゾナンス）を上げて動かすことで生まれます。このジャンルをアシッドと呼びます。

13-3

MAKU：世界を作り直して、気に入ったら「いいね」

やってみる

MAKU は、電源を入れるたびにキーの合ったランダムな環境音楽がずっと鳴るファームです（README より）。

  • HOME を長押し：新しい「世界」に作り直す
  • REC を軽く押す：いまの世界に「いいね」（16個まで）。いいねが増えるほど、新しい世界がいいねに寄っていく
  • KNOB 1〜4：4つのパートの音量。回したパートが「いま触る」パートになる
REC を2秒ほど長押しすると、いいねが全部消えます（README より）。
何が起きたか

何もしなくても音楽が流れ続け、自分の仕事は「聞いて、選ぶ」ことでした。いいねを重ねると、だんだん自分好みの世界が出やすくなります。

それの名前

この節の出典：MAKU の README（github.com/okumurari2/maku）の操作の節

ルールにしたがって機械が自動で作り続ける音楽をジェネラティブ・ミュージック（自動生成の音楽）といいます。

13-4

AMB-1：手入れする音楽

やってみる

AMB-1 も、電源を入れるとすぐ自分で鳴り始めるファームです。説明ページによると、ブライアン・イーノの『Music for Airports』に着想を得ていて、パッド・ベル・ベース・リズム・空間の5つの要素でできています。

  • 鍵盤：スケールの音を、外したり戻したりする
  • REC：いまの和音を止めて、響きだけ残す
AMB-1 のほかのボタン・つまみの働きは、説明ページに書かれていません。実機で確かめてください。
何が起きたか

演奏するというより、庭の手入れのように、音を少し抜いたり残したりして育てる感覚でした。ベルの音は長さの違うループの組み合わせなので、ほとんど同じ形をくり返しません。

それの名前

この節の出典：AMB-1 の説明ページ（charlesvestal.github.io/fm1-amb）

MAKU が「選ぶ」なら、AMB-1 は「手入れする」。どちらもアンビエント（環境音楽）と呼ばれるジャンルです。
