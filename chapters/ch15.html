外とつなぐ（USB録音・CTL-1 で Bluetooth MIDI）

この章は、取扱説明書や各ファームの説明をもとに書いた下書きです。実機で確かめられていない操作は【要実機確認】としています。FM-1 が届いたら、接続診断の「実機確認メモ」をもとに直します。

FM-1 を、ほかの機械やアプリとつなぎます。音を録る（USB オーディオ）と、鍵盤として使う（MIDI）の2つです。スマホの Koala Sampler（コアラ・ラボ）と組み合わせると、遊びが一気に広がります。

15-1

FM-1 の音を USB で録る

やってみる

下の「録音機」で、FM-1 の音を USB で取り込んで録音してみてください（PC か Android の Chrome）。

純正ファームに USB オーディオ（音を USB で送る機能）があるかは、取扱説明書に書かれていません。Felucca と Melodee は README に記載があり、Felucca は「Felucca」という名前の入力として見え、MENU の USB LEVEL で音量の扱いを選べます。

何が起きたか

FM-1 の音が、ケーブル1本でブラウザに入って録音できました。保存したファイルは、スマホの音楽アプリで聞いたり、サンプラーのアプリ（Koala Sampler など）の材料にしたりできます（アプリが読める形式かは要確認）。

それの名前

USB で音を送ることをUSB オーディオ、送る側をオーディオインターフェースと呼びます。FM-1（Felucca）は、オーディオインターフェースにもなるということです。

15-2

純正の Bluetooth MIDI で Koala を弾く

やってみる

FM-1 の HOME を長押しして Bluetooth を ON にします。スマホの Koala で MENU → SETTINGS の MIDI を開き、Bluetooth MIDI の接続ボタンを押すと、近くの機器が一覧に出るので FM-1 を選びます（Koala の公式マニュアルより）。つながったら FM-1 の鍵盤で Koala のパッドが鳴るか試してください。

Koala の MIDI の設定には「どの音で1番目のパッドを鳴らすか」（Note offset）があり、そこから順に次のパッドが鳴ります。FM-1 のいちばん左の鍵盤は、何もしていなければ F3 です（FM-1 の取扱説明書より）。

FM-1 と Koala が実際に Bluetooth でつながるか、遅れが気にならないかは未確認です。
何が起きたか

ケーブルなしで、FM-1 が iPad のアプリの鍵盤になりました。FM-1 の取扱説明書によると、純正でも USB・Bluetooth・3.5mm の3つの MIDI を同時に使えます。

それの名前

MIDI で音を鳴らされる側を音源、鳴らす側をMIDI コントローラーといいます。

15-3

CTL-1：コントローラー専用にする

やってみる

CTL-1 は、FM-1 を MIDI コントローラーにするファームです（README より）。

  • USB と Bluetooth の MIDI（起動のたびに「FM-1」という名前で見つかる）
  • 弾く強さと押し込み（アフタータッチ）に対応。白鍵にスケール、黒鍵にコード
  • 4つのつまみで、4バンクぶんのつまみ情報（CC）を送る
  • 何もつながなくても、内蔵の GM 音源で鳴る

入れたら、接続診断で鍵盤とつまみを動かして、何が届くか見てください。

何が起きたか

純正よりも「ほかの機械を弾く」ことに特化した FM-1 になりました。つまみの CC は、第5章のブラウザのシンセのつまみも動かせる可能性があります（74・71・73・75・72 番を送れば）。

それの名前

GM 音源（ジェネラル MIDI）は、ピアノ・ドラムなどの決まった番号の音がそろった、標準的な音源の決まりです。
