12-1

トラックとページ

やってみる

Felucca を入れたら、ALGORITHM を回してトラック（1〜4）を選びます。上の段のボタンを押すとそのページへ、もう一度押すと次のページへ。HOME で戻ります。HOME を長押しするとメニューが開きます。

トラックごとの音源（エンジン）の選び方の詳しい操作は、README には書かれていません。実機の画面で確かめてください。
何が起きたか

どのページにいても、ALGORITHM で「いま触るトラック」を選ぶのが基本です。HOME のボタンは押すたびに HOME → MIXER → CLOCK と切り替わり、CLOCK でテンポ（BPM）やスウィングを決めます。

それの名前

1つの楽器パートをトラック、トラックごとの音の作り方の種類をエンジンと呼びます。Felucca には FM・ドラムなど13種類以上のエンジンがあります。

12-2

ドラムは「ランダム → 手直し」

やってみる

トラック1のエンジンを DRUM にします。ドラムの画面では、白鍵がマス（ステップ）、黒鍵が楽器（KICK・SNARE・CLAP・ハットなど8種）です。

まずは自分で組まずに、SEQ を長押しして SEQ TOOLS の RANDOM を選び、気に入るまで何度か作り直してください。少しだけ変えたいときは COOK。最後に、キックだけ白鍵で直してみましょう。

何が起きたか

ゼロから打ち込まなくても、ランダムで「それっぽいビート」がすぐできました。気に入るまで作り直し、最後に気になる所だけ手で直す。初心者でも速く進められるやり方です。失敗したら SAVE を長押しで取り消せます。

SAVE 長押しの取り消しが「1回分」か「それまでの編集全部」かは、Felucca の README の中で書き方が分かれています。大事な作業の前には保存しておいてください。
それの名前

機械にランダムで作らせることをジェネレート（生成）といいます。人が全部決めるのでも、全部任せるのでもなく、選んで直すのが作曲の大事な力です（第13章につながります）。

12-3

外れない鍵盤でベースとコード

やってみる

トラック2をベース向きの音にして、SCL のページで QNT を WHITE、ROOT（ルート）と SCALE を選びます。これで白鍵だけでスケールの音が弾けます。

録るときは、MENU（HOME 長押し）→ AUDIO で COUNT-IN を1小節に、CLICK（メトロノーム）を ON。トラックを REC で録音待ちにして PLAY。重ね録りもできます。

トラック3は SCL をもう一度押した CHORD のページで、1つの鍵盤で和音が鳴るようにしてみましょう。

何が起きたか

白鍵だけを弾けば外れない。第4章のスケールの考え方が、そのまま実機の機能になっていました。数え始めがあるので、1拍目から録れます。

それの名前

弾いた音をスケールに寄せる機能をスケールクオンタイズ、1つの鍵盤で和音を鳴らすのがコードキーです。

12-4

エフェクトとミックス

やってみる

FX のページで、トラックのエフェクト（INSERT）と、響きなどに送る量（SEND）を調整します。HOME の MIXER ページで、トラックの音量バランスを整えましょう。

トラックの左右（パン）を決めるつまみの場所は、README に書かれていません。第5章 5-7 のミックスの考え方で、実機の MIXER を探してください。
何が起きたか

第5章 5-6・5-7 でブラウザでやったことが、4トラックの実機でできました。ドラムとベースは真ん中、コードやメロディは少し左右に、響きは控えめに。

それの名前

トラックに直接かけるインサートと、みんなで共有する響きへ送るセンド。どちらも第5章の言葉です。

12-5

保存する

やってみる

再生を止めてから、SAVE を押し、KNOB 1 で保存先を選んで OCT+ を2回。曲全体はプロジェクトとして A〜D の枠に保存できます（README より）。

何が起きたか

音色や曲が FM-1 の中に保存されました。ファームを入れ替える前には、第11章のバックアップを忘れずに。

それの名前

トラック・音色・パターンをまとめた作業全体をプロジェクトと呼びます。
